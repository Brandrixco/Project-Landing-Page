# Project — Landing Page

A minimal, responsive landing page template.

Quick start

1. Open `index.html` in your browser.
2. Use the theme toggle (top-right) to switch light/dark; selection is saved to `localStorage`.

Files

- `index.html` — main page
- `styles.css` — stylesheet (light + dark via `.dark` on `<html>`)
- `script.js` — theme toggle persistence
- `assets/logo.svg` — sample logo

Customize

- Edit colors in `styles.css` root variables.
- Replace `assets/logo.svg` with your brand asset.
